# Event-GS Spatiotemporal Continuum

以事件相机流为输入，融合静态高质量场景数据，实现高速高斯泼溅场景的**时空连续生成**。

## 研究动机

事件相机以微秒级异步输出对数亮度变化，天然刻画高速运动的连续时间信息；而静态高质量场景数据（多视角 RGB、COLMAP 点云、预训练 3DGS）提供高保真、低噪声的空间先验。两者互补：
- **事件流** → 提供高频时间动力学、运动轨迹、形变监督
- **静态高质量场景** → 提供空间外观、几何先验、纹理细节

目标是在时间维度上实现连续（任意时刻可插值可渲染）的 4D 高斯泼溅场景重建，而不仅限于离散帧。

## 方法思路（初步）

1. **静态先验构建**：基于静态高质量多视角数据训练基础 3DGS，作为场景的空间外观与几何底座。
2. **事件流时空监督**：将事件流通过可微事件生成模型（log-luminance 对比度阈值模型）与高斯泼溅的连续时间渲染耦合，形成 per-event 损失，监督高斯的运动/形变。
3. **连续时间变形场**：用连续时间神经 deformation field（或多项式/样条轨迹）参数化高斯的时空轨迹，使任意时刻 t 均可解析地得到高斯位置/旋转/缩放/不透明度，从而实现真正连续时空生成。
4. **静态-动态融合**：以静态先验初始化动态高斯，事件流仅对运动部分施加监督，静态区域保持稳定，避免过拟合噪声。
